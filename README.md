##  Sobre o projeto

O **Clínica Hospitalar** é um projeto acadêmico que consiste no desenvolvimento de um website para uma clínica hospitalar, com o objetivo de apresentar os serviços da instituição e facilitar o contato entre pacientes e a clínica.

A aplicação conta com um formulário de agendamento de consultas, permitindo que os usuários preencham suas informações e solicitem o agendamento de um atendimento.

O projeto foi desenvolvido durante o **3º semestre do curso de Análise e Desenvolvimento de Sistemas (ADS)**, como parte do processo de aprendizagem e aplicação prática dos conhecimentos adquiridos na graduação.

##  Funcionalidades

- Website institucional de uma clínica hospitalar.
- Formulário para agendamento de consultas.
- Coleta e envio de informações preenchidas pelos usuários.
- Integração com banco de dados para armazenamento das informações.
- Comunicação entre o frontend e o backend.

##  Tecnologias e ferramentas utilizadas

| Tecnologia | Aplicação no projeto |
|---|---|
| Spring Boot | Framework utilizado no desenvolvimento da aplicação backend. |
| Express.js | Framework utilizado na comunicação e integração com o banco de dados. |
| SQLite | Banco de dados para armazenamento das informações. |
| Git | Controle de versão do código-fonte. |
| GitHub | Hospedagem e gerenciamento do repositório. |

##  Banco de dados

O projeto utiliza o **SQLite** para armazenamento das informações relacionadas ao formulário de agendamento de consultas.

A integração permite trabalhar com os dados enviados pela aplicação, utilizando o backend para realizar a comunicação com o banco de dados.
